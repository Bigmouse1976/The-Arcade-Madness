# Development Guide

## Setup

1. Run the PowerShell setup script to create the project structure
2. Open the project in your favorite editor (VS Code recommended)
3. Use a local web server to test (Live Server extension for VS Code)

## Adding a New Game

1. Create folder in \js/games/[game-name]/\
2. Create HTML file and JS file
3. Extend the \GameEngine\ class
4. Add game to menu in \js/ui/menu.js\

## Code Standards

- Use ES6+ syntax
- Keep functions small and focused
- Comment complex logic
- Test across browsers
