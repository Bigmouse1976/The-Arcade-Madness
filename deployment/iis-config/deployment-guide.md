# IIS Deployment Guide

## Prerequisites

- Windows Server 2025
- IIS 10.0+
- URL Rewrite Module

## Deployment Steps

1. **Prepare files**
   - Minify JavaScript and CSS
   - Optimize images
   - Test locally

2. **Configure IIS**
   - Create new site
   - Set application pool
   - Configure bindings
   - Copy web.config

3. **SSL Setup**
   - Install certificate
   - Configure HTTPS binding
   - Test HTTP to HTTPS redirect

4. **Optimization**
   - Enable compression
   - Configure caching
   - Enable HTTP/2
